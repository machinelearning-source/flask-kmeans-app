Unsupervised Machine Learning & K-Means

Understanding cluster classification without pre-existing labels.

1. Unsupervised Learning

Unlike supervised learning, unsupervised learning algorithms work with data that does not have predefined labels or target variables. The system attempts to learn the underlying structure of the data independently.

2. Clustering

Clustering is the task of grouping a set of objects in such a way that objects in the same group (called a cluster) are more similar to each other than to those in other groups.

3. How K-Means Works

  • Initialization: The algorithm randomly selects 'K' number of initial centroids.
  • Assignment: Each data point is assigned to its nearest centroid using Euclidean distance.
  • Update: The centroids are recalculated by taking the mathematical mean of all data points assigned to that cluster.
  • Convergence: This iterative process runs until centroids stop shifting or a maximum iteration threshold is hit.
