Concepts: Unsupervised Learning & K-Means

Theoretical foundations of the clustering models implemented in this project.

What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the model is trained with data that has no labels or target variable. The goal is to discover hidden structures, patterns, or groupings within the data on its own. Unlike supervised learning, there is no "correct answer" to compare against; the algorithm explores similarity between records.

In our project: we use 1,000 flight records with only numerical features (distance and duration). No flight is labeled; the algorithm finds the groups.

What is Clustering?

Clustering is the main task of unsupervised learning. It partitions a dataset into groups (clusters) so that:

  • Records inside the same cluster are very similar to each other.
  • Records in different clusters are very different from each other.

Common applications: customer segmentation, image compression, anomaly detection, and document grouping.

How K-Means Works

K-Means is one of the most popular clustering algorithms. Its workflow is:

1. Choose K

Decide the number of clusters (K). In this project K = 3.

2. Initialize centroids

K points are placed as initial cluster centers (random or using smart initialization like k-means++).

3. Assign & update

Each record is assigned to the nearest centroid, then centroids are recomputed as the average of their members.

Steps 3 is repeated until the centroids stop moving (or until a maximum of iterations is reached).

The Role of Centroids and Iterations

  • Centroid: the geometric center of a cluster, computed as the mean of the coordinates of all records in the cluster. It represents the "typical" record of the group.
  • Iteration: one full cycle of (assign records to nearest centroid) + (recompute centroids). Each iteration reduces the total within-cluster variance.
  • Objective: minimize the Within-Cluster Sum of Squares (WCSS), which measures how compact the clusters are.

Euclidean Distance

d(p, c) = √((p1-c1)² + (p2-c2)²)

Each record is assigned to the centroid with the smallest Euclidean distance. This is the metric used in both the manual exercise and the Scikit-Learn implementation.

Binary Classification (Supervised)

As a complement, this project also implements a supervised task: predicting whether a flight is delayed (1) or on time (0) using the same numerical features. Logistic Regression and a Decision Tree are trained and evaluated with accuracy, precision, recall, and F1 score.
