Binary Target Variable: Flight Delay Prediction

Supervised learning over the same flight dataset. The target variable delayed is binary: 1 = delayed (> 15 min), 0 = on time.

Target variable definition

The binary target captures the outcome delay (1) vs no delay (0), built from a real-valued delay time. This transforms the problem into a classification task.

  • Features: distance_km, duration_min.
  • Target: delayed (binary: 0 / 1).

Interpretation

Logistic Regression provides a punctual, interpretable linear boundary: the positive coefficients indicate that longer distance and duration slightly increase the expected probability of delay. The Decision Tree achieves comparable accuracy but is easier to explain for non-technical stakeholders. Recall captures how well the models detect delayed flights, which is the most relevant metric for airline operations.
